# Архитектура проекта TUI RSS/Atom Reader

## 1. Слои приложения
1. **Представление (TUI):** FTXUI, отрисовка и ввод.
2. **Слой приложения (App):** сценарии и состояние сессии.
3. **Ядро (Core):** модели, парсинг XML/HTML, сеть (libcurl). Отдельный CMake target.

## 2. Точки расширения
1. Форматы лент (`IFeedParser`).
2. Отрисовка HTML-тегов (`ITagRenderer`).
3. Источник данных (`IFeedStorage`).

## 3. Паттерны GoF
1. **Factory Method** — выбор разборщика ленты.
2. **Visitor / Strategy** — рендеринг HTML-дерева.
3. **Observer** — уведомление о фоновой загрузке.
4. **Command** — обработка горячих клавиш.
